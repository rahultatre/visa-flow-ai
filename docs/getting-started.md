# Getting Started

## Clone

```bash
git clone https://github.com/rahultatre/visa-flow-ai.git
```

---

## Backend

```bash
cd backend

npm install
```

Create

```
.env
```

Example

```env
OPENAI_API_KEY=your_api_key
PORT=3000
USE_MOCK_AI=true
```

Run

```bash
npm run dev
```

Server

```
http://localhost:3000
```

---

## Frontend

```bash
cd frontend

npm install

ng serve
```

Application

```
http://localhost:4200
```
